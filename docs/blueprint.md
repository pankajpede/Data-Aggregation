# **App Name**: FinSight

## Core Features:

- Dashboard View: Dashboard for quick overview of recent activities and key metrics.
- Data Extraction Preview: PDF Parsing Viewer for previewing extracted tables.
- Column Configuration Wizard: Column Wizard for structured column selection and configuration.
- Table Visualization: Table Viewer to preview pillar-wise mapped data tables.
- AI-Powered Column Labeling: AI tool to help you label different kinds of columns after PDF extraction.
- Export Module: Functionality to download into multiple formats (Excel, CSV, JSON)
- Reuse/reprocess prior uploads and configurations: Session Management
- PrimeNG Components: PrimeNG components will be used to construct the UI

## Style Guidelines:

- Primary color: Deep Navy (#0B1F3A) for a professional and trustworthy feel.
- Background color: Desaturated navy (#13263F) to provide a dark, but not overpowering, backdrop to the UI.
- Accent color: Emerald (#2ECC71) for CTAs and key highlights, providing contrast and indicating actionable elements.
- Font: 'Inter' (sans-serif) for a compact, modern, financial-grade look across all text elements; prioritizes readability and data density. Note: currently only Google Fonts are supported.
- Tight padding (4–12px) is implemented to maximize data display within PrimeNG tables and components. Full mobile/tablet/desktop support.
- Utilize minimalistic icons to represent different financial concepts and actions.
- Subtle transitions and animations on data updates and interactions to provide a smooth user experience.
